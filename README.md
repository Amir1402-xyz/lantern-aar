# lantern-aar

Builds `lanternsdk-android.aar` from [getlantern/lanternsdk-android](https://github.com/getlantern/lanternsdk-android)
in CI, so the library can be dropped into an Android app without a local Go or NDK setup.

The finished AAR lands on the `aar-latest` release. Build logs go to the `ci-logs` branch.
